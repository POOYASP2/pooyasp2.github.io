## NAME

Pooya Sharifi — software developer turned cybersecurity student, based in Turin

## DESCRIPTION

Hi, I'm Pooya. I like taking an idea all the way to production: building it, automating how it ships, and keeping it secure.

I spent about four years as a frontend developer, building web apps in React, Vue and Next.js. Along the way I got hands-on with the other half of shipping software: GitLab CI/CD pipelines, automated tests and deployments, and error monitoring.

Now I'm doing a master's in cybersecurity at Politecnico di Torino. The part I enjoy most is where security meets machine learning: using data to spot attacks. In my [DDoS detection project](https://github.com/POOYASP2/DDoS-attacks-detection), our model told benign traffic apart from 11 types of DDoS attack with 90% accuracy, and we used SHAP to explain which traffic features give each attack away. I also like the attacker's side, because it shows what defenders should look for: I did a hands-on OWASP web security workshop, and I take part in PoliTo CTFs (our team placed 15th of 279 at mOleCon 2026).

On the engineering side, I'm learning DevOps and platform engineering so I can build delivery pipelines and infrastructure with security in mind from the start.

The [blog](/blog/) is where I write down what I learn. The [journal](/journal/) is for everything else: books, films, music, and whatever I'm thinking about.
